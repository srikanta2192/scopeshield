# ScopeShield project skills

Store skill files used for this project in this directory, as requested by the user.
Use one directory per skill, with its instructions in `SKILL.md` and any supporting
resources alongside it. Prefer these project-local copies when available.

Existing global skill files have not been copied here because this session cannot
read their source directory. Copy the complete skill and its referenced resources
when access becomes available; do not reconstruct missing instructions.
